# Portfolio | Matheus de Castro

Portfólio profissional bilíngue desenvolvido com Jekyll e publicado pelo GitHub Pages.

## Conteúdo

- Apresentação profissional
- Foco técnico
- Projetos selecionados
- Formação e experiência
- Links para GitHub e LinkedIn
- Resumo em inglês

## Executar localmente

~~~bash
bundle install
bundle exec jekyll serve
~~~

Depois, acesse [http://localhost:4000](http://localhost:4000).
