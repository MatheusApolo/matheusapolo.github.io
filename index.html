Implantação do PortfolioHUB

A implantação foi pensada de forma simples: o GitHub guarda os repositórios, o GitHub Pages publica esta página, o LinkedIn ajuda na apresentação profissional e o YouTube será usado para a apresentação final do trabalho.

Organização

Os principais links do projeto ficam visíveis na página inicial, facilitando o acesso do professor e de outras pessoas.

Segurança

Foram considerados cuidados básicos, como não publicar dados sensíveis, manter arquivos públicos apenas quando necessário e testar os links antes da entrega.
